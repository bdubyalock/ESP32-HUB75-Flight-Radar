About This Project

This project is a flight tracking system built on the ESP32 platform, utilizing the HUB75 LED matrix display. It provides real-time flight information and visualizations, allowing users to monitor air traffic in their area. The README for this project can be found on GitHub at https://github.com/bdubyalock/ESP32-HUB75-Flight-Radar.
